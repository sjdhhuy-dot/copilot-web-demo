About

我叫林岚，喜欢在慢节奏里做清晰的事。

我是一名产品与前端工程师，常常在设计、用户体验和工程实现之间来回移动。我的工作不是为了制造复杂，而是为了把复杂的问题拆开，让它们变得更简单、更可被理解。

我写作，来自于对知识复用的热爱；我做产品，来自于对体验细节的关注；我做技术，来自于对长期价值的坚持。写作帮助我把思考沉淀下来，把日常的观察变成经验。

我的专长

  • 产品思维：需求拆解、策略评估和迭代设计
  • 前端工程：HTML / CSS / JavaScript / TypeScript
  • 体验设计：组件系统、信息架构与交互细节

我关注的事

  • 清晰度：让复杂内容更容易被理解
  • 节奏：让产品和界面更适合真实使用场景
  • 持续写作：把经验转化成可复用的知识
