About

我叫刘苏晋，喜欢在慢节奏里做清晰的事。

我是一名软件开发与人工智能方向的研究生，致力于学习技术并将其转化为现实。我的的目标是成为一名出色的计算机大牛，能独立开发自己脑海中中的智能，能使生活更加便利。

我写作，来自于对知识复用的热爱；我做产品，来自于对体验细节的关注；我做技术，来自于对长期价值的坚持。写作帮助我把思考沉淀下来，把日常的观察变成经验。

我的专长

  • 产品思维：需求拆解、策略评估和迭代设计
  • 前端工程：HTML / CSS / JavaScript / TypeScript
  • 体验设计：组件系统、信息架构与交互细节

我关注的事

  • 清晰度：让复杂内容更容易被理解
  • 节奏：让产品和界面更适合真实使用场景
  • 持续写作：把经验转化成可复用的知识
